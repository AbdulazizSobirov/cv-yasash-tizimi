# CV Studio

Production-style static CV Builder built with React, Vite, TypeScript, Tailwind CSS, Lucide React, jsPDF, html2canvas, docx and file-saver.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

All CV data is stored in browser localStorage under `cv-studio-data`. No backend is used.
