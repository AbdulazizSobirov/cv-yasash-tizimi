# CV Studio — Onlayn CV Generator 📄✨

Tayyor va professional shablonlar yordamida tezkorlik bilan mukammal CV (rezume) yaratish hamda ularni yuklab olish imkoniyatini beruvchi zamonaviy veb-ilova. Loyiha to'liq foydalanuvchining kompyuterida (localda) ishlashga mo'ljallangan.

---

## 🌟 Asosiy Imkoniyatlari

* **Turli xil shablonlar:** Bir nechta dizayn va shablonlar ichidan o'zingizga mosini tanlash imkoniyati.
* **Ma'lumotlarni qulay kiritish:** Shaxsiy ma'lumotlar, ish tajribasi, ko'nikmalar, tillar va ta'lim yo'nalishlarini qulay interfeys orqali to'ldirish.
* **Yuklab olish (Download):** Tayyor bo'lgan CV-ni kompyuterga professional **PDF** yoki **DOCX (Word)** formatlarida yuklab olish.
* **Ma'lumotlar xavfsizligi:** Barcha kiritilgan ma'lumotlar brauzerning shaxsiy `localStorage` xotirasida saqlanadi. Hech qanday backend (ma'lumotlar bazasi) ishlatilmaydi, ma'lumotlaringiz xavfsiz va faqat o'zingizda qoladi.
* **Ko'p tillilik:** Shablon tilini foydalanuvchi xohishiga qarab o'zgartirish tizimi (O'zbekcha, Ruscha va boshqalar).

---

## 🛠 Ishlatilgan Texnologiyalar

Loyiha quyidagi zamonaviy vositalar va kutubxonalar yordamida qurilgan:
* **Framework:** React + Vite + TypeScript (Tezkor va xavfsiz arxitektura)
* **Styling:** Tailwind CSS (Zamonaviy va moslashuvchan dizayn)
* **Ikonkalar:** Lucide React
* **Eksport/Yuklab olish:** `jsPDF`, `html2canvas`, `docx` va `file-saver`

## 🚀 Localda Ishga Tushirish Qo'llanmasi

Loyihani o'z kompyuteringizda ishga tushirish uchun quyidagi ketma-ketlikni bajaring:

### 1. Loyihani yuklab olish (Clone)
Terminal yoki konsolni ochib, loyihani kompyuterga yuklab oling va papka ichiga kiring:
```bash
git clone https://github.com/AbdulazizSobirov/cv-yasash-tizimi.git
cd cv-yasash-tizimi
```

### 2. Zarur kutubxonalarni o'rnatish (Dependencies)
Loyiha ishlashi uchun kerakli bo'lgan barcha `node_modules` paketlarini o'rnating:
```bash
npm install
```

### 3. Loyihani ishga tushirish (Development Server)
Dasturni local serverda ishga tushiring:
```bash
npm run dev
```
Buyruq bajarilgandan so'ng terminalda mahalliy havola (odatda `http://localhost:5173`) paydo bo'ladi. Uni brauzeringizda ochib loyihani ishlatishingiz mumkin.

### 4. Loyihani yig'ish (Build & Preview)
Agar loyihani production (tayyor mahsulot) holatiga keltirmoqchi bo'lsangiz:
```bash
npm run build
npm run preview
```
